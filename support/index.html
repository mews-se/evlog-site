Support

EVLog is a free, unofficial iPhone client for TeslaMate.

It reads drives, charges, statistics and battery health from your own instance and shows them on the phone. It connects only to servers you run yourself.

Requirements

  • A running TeslaMate instance
  • teslamateapi reachable from your phone — the app's main data source
  • Optionally Grafana, used for the visited-places map, battery health and a few queries the API does not expose
  • Optionally a Tessie API key, only to fill in charging costs TeslaMate never records

All addresses are configured under Settings in the app. The defaults point at a LAN address and will need changing.

Common questions

The app cannot reach my server. Check that teslamateapi answers from the phone's network, and that the address in Settings includes the port. On a plain HTTP address, iOS will ask for permission to access devices on the local network the first time.

Some charging costs are missing. TeslaMate never receives Supercharger costs from Tesla. They can be entered manually in TeslaMate, or filled in automatically if you add a Tessie API key in Settings.

The visited-places map and battery health are empty. Both read from Grafana rather than teslamateapi. Add your Grafana address in Settings.

Questions and bug reports

Open an issue on GitHub, which is the best place for anything reproducible, or write to evlog@notmydomain.org.
